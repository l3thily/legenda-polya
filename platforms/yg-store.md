# Инап-покупки — локальные варианты

Модуль подключается **только `build-yg.sh`**. `index.html`, веб-сборка, сайт и сервер не меняются. В Консоли Яндекс Игр товары пока не создавались; архив не загружался.

## Посмотреть и выбрать

```sh
./build-yg.sh --preview
python3 -m http.server 8099 --bind 127.0.0.1 --directory dist-yg-preview
```

Открыть http://127.0.0.1:8099/ (`?lang=en` — английский). Магазин откроется сам. «Примерить» временно показывает эффект; «Купить» открывает **локальный симулятор**, в котором можно выбрать успех, отмену или ошибку. Симулятор сохраняет тестовые покупки только в этом браузере и на этом локальном адресе. «Сбросить тестовые покупки» очищает только его тестовые чеки и настройки, карьеры не затрагиваются.

Четырнадцать кандидатов. Оформление — постоянные товары, игровые преимущества — расходуемые. Значения TST — условные цены для сравнения в макете, не реальные цены или рекомендации к запуску.

Игровые бонусы — расходуемые товары: каждая покупка даёт одно применение, которое сгорает при старте следующей обычной карьеры игрока; повторные покупки не ограничены. Условия испытаний и комнат не меняются. Бонусы влияют на развитие и могут влиять на рекорды/GOAT. Перед активацией в Консоли ID этих двух позиций нужно создать как расходуемые. Обработчик сначала записывает токен и применение через `player.setData`, затем вызывает `consumePurchase`; необработанные чеки повторно сверяются при следующем запуске. Оформление остаётся постоянным; карьеру и тренерский режим можно начать бесплатно.

## Обычная сборка для Яндекса

```sh
./build-yg.sh
```

Результат: `dist-yg/`, `platforms/legenda-polya-yg.zip`. В нём **нет** симулятора, тестовых платежей и автозапуска магазина. Предпросмотр собирается отдельно в `dist-yg-preview/` и никогда не архивируется этим скриптом.

В реальной сборке показываются только товары с поддерживаемыми ID, возвращённые `getCatalog()`; цена, название, описание и иконка валюты приходят из SDK. Если каталог пуст, предложений нет. Для отключения кандидата достаточно не активировать его в Консоли. Нельзя активировать неподдерживаемые ID: соответствие всех активных товаров витрине проверяется при модерации.

Покупки выполняются через `getPayments({signed:false})` → `purchase({id})`. Перед оплатой игра предлагает штатный вход в Яндекс, если пользователь не авторизован. `getPurchases()` восстанавливает постоянные покупки при загрузке и по кнопке. Постоянные покупки **не консумируются**, чтобы они оставались доступны на других устройствах. Локальный флаг не выдаёт право на товар; двойной клик не запускает повторную оплату. При ошибке восстановления автоматическая реклама не запускается, чтобы не показывать её купившему отключение рекламы игроку.

Постоянные покупки восстанавливаются через `getPurchases()` и не консумируются. Расходуемые чеки сначала записываются в `player.setData({legendaShop:...}, true)`, затем обрабатываются `consumePurchase()`; если консумирование временно не прошло, токен уже учтён и повторная проверка завершит обработку без повторной выдачи. Настройки оформления и остатки расходуемых применений хранятся через `player.setData`. Звук и GameplayAPI приостановлены во время магазина/оплаты. Интерфейс RU/EN, на мобильном примерочная переносится над товарами.

## Перед реальным запуском

1. Выбрать товары и цены; подключить инапы в Консоли и создать только выбранные ID с соответствующими описаниями RU/EN.
2. **Доработать облачное сохранение карьер для Яндекс-сборки.** Сейчас игра хранит карьеры в браузере; этот модуль синхронизирует покупки и оформление, но не переносит карьеры. Для выпуска с инапами Яндекс требует доступность прогресса с других устройств. У `player.setData` лимит 200 КБ на игрока; нельзя просто выгрузить туда все 15 больших слотов. Способ синхронизации нужно выбрать и проверить отдельно до публикации.
3. Проверить реальный SDK на тестовом логине Яндекса: отмена, повторный вход, обновление сразу после оплаты, другое устройство, смена аккаунта, валюта TST через debug-панель. Локальный симулятор этого не заменяет.
4. После выбора и проверки отдельно загрузить архив в Консоль. В текущей задаче загрузка и деплой не выполняются.

Официальные документы: [SDK покупок](https://yandex.ru/dev/games/doc/ru/sdk/sdk-purchases), [требования к инапам](https://yandex.ru/dev/games/doc/ru/requirements/1/13), [сохранение данных игрока](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player).

## Проверки

```sh
node --test tests/yg-store.test.js
node --test tests/yg-store-build.test.js
```

Первый набор проверяет восстановление, отмену, ошибки, повторные клики, смену аккаунта, поддельные/неверные ответы и сохранение постоянных покупок. Второй использует собранные файлы для проверки изоляции симулятора и реального запрета автоматической рекламы после покупки.
